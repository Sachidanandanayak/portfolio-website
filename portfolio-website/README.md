
# 🚀 3D Developer Portfolio Website (React + TypeScript + Three.js)

[![3D portfolio preview (click to watch video)](./Screenshot_2026-04-08_22-10-00.png)](./screen-capture%20(13).webm)

A modern, high-performance **3D developer portfolio website** built with **React**, **TypeScript**, **Three.js**, **GSAP**, and **WebGL**.

If you’re a developer looking for a **portfolio template** that feels premium, interactive, and memorable—this repo is for you.

> Live preview: https://Sachidanandanayak.github.io/

---

## ✨ Highlights

- **3D / WebGL experience** powered by **Three.js**
- Smooth animations with **GSAP**
- Modern **React + TypeScript** codebase
- Fast, responsive UI (desktop + mobile)
- Designed for developers, engineers, programmers, and creators

## 🚀 Getting Started

### 1) Clone

```bash
git clone https://github.com/Sachidanandanayak/portfolio-website.git
```

3. **Install Dependencies**
```bash
npm install
```

4. **Run the Development Server**
```bash
npm run dev
```

## 📂 Project Structure

```text
src/
├── components/     # React components (Navbar, About, Work, etc.)
├── context/        # React context (LoadingProvider)
├── data/           # Data files (3D animation data)
├── pages/          # Application pages (Play, Home)
├── styles/         # CSS and animation styles
├── utils/          # Utility functions
├── App.tsx         # Main application component
└── config.ts       # Centralized configuration file
```

## 🔧 Core Technologies

- **React + Vite**: Fast, modern frontend framework
- **TypeScript**: Static typing for robust code
- **Three.js**: 3D rendering engine for the interactive character
- **GSAP**: Professional-grade animation library
- **Lenis**: Smooth scrolling experience
- **Framer Motion**: React animation library

## 💬 The `Play.tsx` Chat Feature

The portfolio includes a unique interactive feature where visitors can chat with an AI representation of the developer. This uses a custom `RedoxChessEngine` and a conversational AI prompt located in `Play.tsx`.

You can modify the `SYSTEM_PROMPT` in `Play.tsx` to teach the AI about your own background, skills, and projects so it responds accurately to your visitors!
